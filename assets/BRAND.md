# 통역톡 / Interpreter Talk

The original brand image is `images/interpreter-talk.png`. It is used on the home and authentication screens and exported as browser/PWA app icons by `tools/export_brand_assets.py`.

Created with the built-in image generation tool for this project. Final prompt: “A single square original application icon for 통역톡 / Interpreter Talk; two rounded interlocking speech bubbles implying two people understanding each other; no text or flags; white and mint symbol on deep cobalt/indigo; centered, strong silhouette, safe padding, crisp 2D artwork, no existing messenger logo imitation.”

The original BridgeChat image remains preserved in the repository for provenance but is not used in the current UI. Original upstream attribution remains in `LICENSE.md` and `NOTICE.md`.

## Exact built-in generation prompt

Use case: logo-brand. Create one original production-ready square application icon for a Korean-Mongolian messenger named 통역톡 / Interpreter Talk. The icon must also serve as the main-page brand image. No text, no letters, no flags. A single clean memorable symbol: two softly rounded interlocking speech bubbles forming a balanced circular exchange, implying two people understanding each other. Warm, trustworthy, approachable modern messenger. Simple flat vector-like raster artwork, strong silhouette at 48 px, generous 18% safe padding. Deep cobalt/indigo rounded-square background filling the square; one white speech bubble and one bright mint speech bubble with elegant negative space. Front-facing 2D, crisp smooth edges, subtle depth only, no small decorations, no frame, no mockup, no watermark. Entire composition centered, app-store icon quality. Do not resemble WhatsApp, Telegram, LINE or any existing messenger logo. Output a single square icon.
